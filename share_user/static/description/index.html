Imagine the following scenario:

You have 3 sales teams, and each team has around 5 salespersons. What challenges could this create for your business?

1. In theory, you would need to create one internal user for each employee (salesperson), This is a big cost if you are using the Enterprise version, and configure access rules for each individual user.

2. If multiple employees share the same user account, when you look at the chatter of a document record, you won't know which employee made the changes to that record.

3. Another difficulty is that you won't know which employee created the document record and which employee last modified it. If that document record does not have a chatter.

4. If you have a group chat in Odoo Discuss, and multiple employees share the same user account, you also won't be able to konw which employee sent which message.

With this app, all the above problems are solved. It allows multiple employees to share the same user account, and each employee can use their own PIN code to log in to Odoo, while ensuring each employee has their own secure access



This solution brings the following benefits to you.
1. If you are using the Enterprise Edition, it will save costs on purchasing additional users as your business expands.
2. Easily add or remove employees from the shared account list.
3. One team only needs one internal user, saving time on configuring access rights and rules.
4. Easily identify which employee made changes to any document record.

1. Configuration.
- Go to User access right setting, and enable "Allow sharing internal user"

- Go to the user account that you want to share with multiple employees.

- Enable "Share Account" option and then select multiple employees that you want to share this user account with..

2. Employee authentication using a PIN code.
- Each employee needs to set up a PIN code.

- In the example below, the user account "demo" is shared with two employees: "Abigail Peterson" and "Anita Oliver".
- When an employee logs into Odoo, they need to enter the username and password of the "demo" user first.

- After logging in, they need to go through an additional employee authentication step.

- Select an employee and enter the PIN code.
- After the employee authentication is successful, the employee's avatar will be displayed at the top right of the dashboard instead of the user's avatar.


3. Show the employee who modified the document record in the chatter.
- After an employee logs into Odoo, when they modify any document record, their name will appear in the chatter panel instead of the "demo" user's name.

- This feature will be applied to all models in Odoo, including models from custom apps. Any custom apps installed after this app is installed will still have this feature.

4. Identify the employee messages in the Discuss module.
- In the Discuss module, you can easily see which employee sent each message.

- Imagine you have a group chat for 3 teams, each team with 5 people. You would normally need 3 internal users for the 3 teams. In the group chat, there are a total of 15 employees chatting, but you only need 3 internal users and can still clearly see which employee sent each message.
